Setup Guide

Get up and running in 5 minutes

Step 1 — Configure SMTP (Hostinger)▼
🟠 Hostinger Email setup
  1. Log in to hPanel → Emails → Manage
  2. Create an email account if you haven't already
  3. Go to SMTP Config and click the Hostinger preset
  4. Enter your full email as the username and the email account password
  5. Use port 465 with SSL (pre-filled)
  6. Click Test Connection to verify
Step 2 — Prepare your CSV▼

Your CSV must have at least these two columns:

email,first_name,company john.doe@acme.com,John,Acme Corp sarah@xyz.com,Sarah,XYZ Ltd
Step 3 — Customize templates & attachments▼

Go to Email Templates. Edit subject lines and body text. Use {{First Name}} for personalization. Each template has its own attachment section.

Step 4 — Bulk-select contacts and launch▼

In Launch Campaign: (1) Pick which email template to send. (2) Use the contact table to check individual rows, use "Select visible" for filtered groups, or check the header checkbox to toggle all. (3) Use the status filter pills to narrow down to e.g. only "New" contacts. (4) Optionally set CC/BCC override. (5) Send a test email first, then launch. After sending, the tracker updates automatically with the new status and last-sent timestamp.

Step 5 — Manage responses & follow-ups▼

Use the Contact Tracker to update statuses:

  • Booked Call → sends Call Confirmation email immediately
  • Call Done → sends Post-Call Next Steps email
  • Not Interested → sends Graceful Exit email
  • No Response → follow-ups queue automatically
Running the backend (Node.js server)▼
npm install nodemailer express cors node server.js # Server starts on http://localhost:3333
